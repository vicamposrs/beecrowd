# 1113 - Ascending and Descending

(Crescente e Decrescente)

## Resumo
Vai lendo dois valores de cada vez ( X e Y ) até que sejam iguais, caso eles sejam diferentes, diz se eles estão em ordem crescente ou decrescente. 

---

**Abordagem:** Um laço `while(true)`, onde se lê os dois valores e, se `X == Y`, dá `break` para terminar o loop antes de qualquer comparação. Caso contrário, define em que ordem estão.
Utiliza um `StringBuilder` para armazenar "Crescente" ou "Decrescente" a cada iteração e exibe tudo no final.
