# 1006 - Average 2

(Média 2)

## Resumo
Lê três valores de ponto flutuante, calcula a media ponderada entre eles com os pesos `2`, `3` e `5` e exibe o resultado com uma casa decimal.

---

**Abordagem:** Lê-se A, B e C e calcula-se:
$$
\text{média} = \frac{A \times 2 + B \times 3 + C \times 5}{10}
$$

Na implementação em C, utiliza `scanf` para a leitura e `printf` com `%.1f` para a saída. 
Em Java, utiliza `Scanner` para a leitura e `System.out.printf` com `%.1f` para exibir o resultado.
