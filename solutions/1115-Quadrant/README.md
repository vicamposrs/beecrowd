# 1115 - Quadrant

(Quadrante)

## Resumo

Lê pares de coordenadas `x` e `y` e determina a qual quadrante cada ponto pertence. A leitura termina quando pelo menos uma das coordenadas é igual a zero.

---

**Abordagem:** Utiliza um ``while`` para ler cada par de coordenadas. Caso `x` ou `y` igual a zero,o laço é encerrado  com `break`, usa uma cadeia if else para verificar se y > 0 e x > 0 para determinar o quadrante. Guarda os quadrantes em um StringBuilder e exibe ao fim.
