# 1094 - Experiments

(Experimentos)

## Resumo
Lê um valor que indica a quantidade de casos que seguem. Para cada caso se lê um inteiro de 1 a 15 e um character ( C , R , S)
representando Coelho, Rato e Sapo respectivamente.
Conta-se o total de cobaias, quantas de cada animal e a porcentagem sobre o total.

---

**Abordagem:**  Vai lendo os valores, em um `for` de 0 a `N - 1`, utilizando um `switch` no char que representa o animal, para incrementar o contador correspondente (coelhos, ratos ou sapos) com o valor do atual caso.
