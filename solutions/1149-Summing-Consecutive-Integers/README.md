# 1149 - Summing Consecutive Integers

(Somando Inteiros Consecutivos)

## Resumo
Lê dois valores inteiros `A` e `N`, garantindo que `N > 0`, e exibe a soma dos `N` números consecutivos a partir de `A`.

---

**Abordagem:** Utiliza um laço `do while` para ler e garantir que `N` seja positivo. Em seguida, utiliza um `for` com `i` variando de `0` a `N - 1`, que a cada repetição vai adicionando `(A + i)` a soma. Ao final exibe a soma.
