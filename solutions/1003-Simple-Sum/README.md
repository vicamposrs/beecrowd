# 1003 - Simple Sum

(Soma Simples)

## Resumo
Lê dois valores inteiros e exibe a soma entre eles.

---

**Abordagem:** Armazena os dois valores lidos, calcula a soma e exibe o resultado precedido por `SOMA =`, conforme o formato solicitado pelo problema.
