# 1150 - Exceeding Z

(Ultrapassando Z)

## Resumo
Lê dois valores inteiros `X` e `Z`, garantindo que `Z > X`, e exibe a quantidade de números consecutivos que tem que ser somados a partir de `X` para alcançar `Z`.

---

**Abordagem:** Utiliza um laço `do while` para ler e garantir que `Z` seja maior do que `X`. Em seguida, utiliza um `while` para acumular os números consecutivos a partir de `X` e incrementar um contador a cada valor somado. O laço termina quando a soma se torna maior que `Z`. Ao final, exibe a quantidade de números utilizados.
