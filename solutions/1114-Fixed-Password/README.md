# 1114 - Fixed Password

(Senha Fixa)

## Resumo
Continua lendo números enquanto o valor lido for diferente da senha fixa (2002). 

---

**Abordagem:** Um laço `while`, que verifica se número digitado é diferente de 2002.
Se for diferente, exibe "Senha Invalida".
Se for igual, sai do loop e exibe "Acesso Permitido".
